Цель: человек открывает приложение с телефона, выбирает навык в каталоге, включает
камеру, проходит шаги урока по реально распознанным позе и мячу, завершает эфир
и видит честный итог.

Проверять на опубликованном HTTPS-адресе. Локальная проверка подходит для UI,
но не заменяет проверку камеры на физическом телефоне.
