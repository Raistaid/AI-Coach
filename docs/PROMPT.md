```text
Роль: ты root-агент проекта Aimo (репозиторий существует, правила в AGENTS.md).
Проект участвует в хакатоне. Цель — максимальный балл по каждому критерию:
Оригинальность 25%, Польза 20%, Работоспособность 20%, Качество исполнения 15%,
Работа в команде 10%, Использование ИИ 10%.
Каждую задачу связывай с критерием. Приоритет — по весу критерия.

═══ ПРОДУКТ ═══
Aimo — нейро-тренер в формате прямого эфира. Человек ставит телефон,
запускает вертикальную трансляцию как в Instagram Live, и ИИ-тренер в реальном
времени пишет в ленту комментариев, что делать прямо сейчас и как получается.
Флагманский сценарий — новичок учится чеканить мяч.
Весь ИИ работает на устройстве: без сервера, без API-ключей, видео никуда не уходит.

Проблемы, которые решаем (для питча и для логики продукта):
1. Персональный тренер дорогой и недоступен → тренер в кармане бесплатно.
2. Ошибки техники ведут к травмам → тренер замечает опасную технику сразу.
3. Новички бросают без обратной связи → уроки, прогресс, похвала по фактам.

═══ ОРИГИНАЛЬНОСТЬ: три фишки, работают вместе ═══
1. Уроки с переходом по наблюдениям. Тренер не пускает дальше, пока модель
   реально не увидела выполнение шага. Как живой тренер, а не таймер.
2. Лента эфира. Комментарии тренера всплывают поверх вертикального видео,
   как сообщения в Instagram Live. Старые гаснут, важные подсвечены.
3. Характер тренера на выбор: «Строгий», «Весёлый», «Спокойный».
   Меняет тон фраз и голос, но не меняет факты и правила безопасности.

═══ КАТАЛОГ НАВЫКОВ ═══
- Экран каталога: карточки навыков с уровнем, длительностью, числом уроков
  и схемой установки камеры.
- Каждый навык — отдельный модуль данных: id, название, уроки, условия перехода,
  ситуационные правила, банк фраз, метрики, нужен ли мяч.
  Новый навык добавляется одним файлом.
- В каталоге только работающие навыки. Пустых карточек «скоро» нет.
- Флагман: «Чеканка мяча» (полностью). Также: «Приседания», «Баланс на одной ноге»
  (перенести существующую логику в формат каталога).

Уроки чеканки:
  Шаг 1. Стойка: в кадре всё тело, опорное колено мягкое, 3 секунды.
  Шаг 2. Подъёмы стопы без мяча: 6 невысоких контролируемых подъёмов.
  Шаг 3. Подброс руками → одно касание → поймать. 3 удачные попытки.
  Шаг 4. Серия: несколько касаний подряд в ровном ритме. Цель растёт: 3 → 5 → 10.

Ситуационные подсказки (все — по реальным данным моделей):
  - опорная нога прямая → «Согни опорное колено, будет устойчивее»;
  - стопа выше колена → «Короче удар, мяч уйдёт высоко»;
  - корпус заваливается → «Плечи над тазом»;
  - руки прижаты → «Разведи руки для баланса»;
  - мяч ушёл в сторону → «Бей серединой подъёма, носок на себя»;
  - мяч упал → короткая поддержка и что исправить;
  - получилось → похвала с фактом: «5 касаний подряд, колено мягкое».

═══ ИИ-ТРЕНЕР: три уровня, всё локально ═══
Уровень 1 — зрение, каждый кадр анализа:
  - MediaPipe Pose Landmarker: поза, углы суставов, фазы движения.
  - MediaPipe Object Detector (COCO, класс «sports ball»): мяч, его высота,
    касания и падения. Касание = разворот траектории мяча рядом со стопой.
Уровень 2 — правила и банк фраз, мгновенно (< 200 мс):
  - Правило определяет ситуацию, фраза берётся из банка под характер тренера,
    в неё подставляются реальные числа.
  - Банк большой: не меньше 5 вариантов на ситуацию и характер, без повторов подряд.
  - Этот уровень работает на любом телефоне и офлайн. Это основа эфира.
Уровень 3 — маленькая LLM в браузере через WebLLM (@mlc-ai/web-llm, версия 0.2.86):
  - Модель по умолчанию Qwen2.5-1.5B-Instruct-q4f16_1-MLC (хорошо пишет по-русски).
    Для слабых устройств Qwen2.5-0.5B-Instruct-q4f16_1-MLC.
  - Включается пользователем в настройках («Живой тренер, бета»). Перед загрузкой
    показать размер, при загрузке — прогресс. Модель кешируется браузером.
  - Нужен WebGPU. Нет WebGPU или не хватает памяти → честное сообщение
    и работа на уровнях 1–2.
  - Раз в 10–15 секунд получает ТОЛЬКО числовую сводку: шаг урока, счётчики,
    частоту ошибок, качество видимости, характер тренера. Кадров модель не видит.
  - Пишет одну короткую живую фразу в ленту и итоговый разбор после тренировки.
  - Ответ проверяется кодом: длина, русский язык, все числа в ответе есть в сводке.
    Не прошёл проверку → фраза из банка уровня 2.
  - Генерация не должна тормозить анализ позы: если кадры анализа проседают
    ниже 8 в секунду, LLM пропускает очередь. Работать в Web Worker.
  - При остановке и уходе со страницы вызвать unload() и освободить GPU.

═══ ИНТЕРФЕЙС ЭФИРА ═══
- Вертикальное видео на весь экран телефона.
- Сверху: LIVE, таймер, шаг урока и прогресс «3/6», выбранный тренер.
- Снизу: лента комментариев, голос по умолчанию, не чаще фразы в 4–6 секунд.
  Фразы LLM помечены значком «живой тренер».
- Крупные кнопки: пауза, камера, голос, завершить.
- Итог: что получилось, главная ошибка, следующий шаг, история прогресса
  по навыку. Хранится локально, без видео.

═══ РАБОТОСПОСОБНОСТЬ ═══
- Основной сценарий целиком на телефоне: каталог → чеканка → эфир → итог.

  вместе с детектором мяча. Если не тянет — детектор реже, поза чаще.
- Страховка для защиты: заранее записанное видео чеканки, которое приложение

═══ ЧЕСТНОСТЬ (не нарушать) ═══
```

## Решения, принятые после исходного промпта (25 октября)

Исходный промпт выше сохранён без изменений. Команда уточнила его так:

- Главный экран — чат с тренером, а не каталог. Тренер подбирает маршрут из навыков
  по цели своими словами и поддерживает обычный разговор («как дела», «устал», «болит»).
  Числа в ответах только из истории на устройстве; при боли — совет остановиться
  и обратиться к врачу, одинаковый для всех характеров.
- Вход — локальный профиль на устройстве (имя и цвет аватара), без пароля и сервера.
  Каждый новый заход открывает новый чат; история чатов — в панели по свайпу.
- Дизайн в цветах Facebook: синий #0866FF, серый фон, скруглённые карточки, светлая
  и тёмная тема. Хостинг — GitHub Pages, публикация автоматически из `main`.
- Камера: фронтальная по умолчанию, показывается весь кадр (то, что анализирует
  модель), на задней камере — широкий угол 0.5×, если он есть в телефоне.
- После эфира — карта ритма по засчитанным касаниям, подъёмам или повторам.
- Приложение и модели зрения работают без сети после первого захода (сервис-воркер).
