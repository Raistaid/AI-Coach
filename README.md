# AI-Coach

Мобильная тренировочная студия: вертикальное видео, распознавание позы и обратная связь поверх кадра. Интерфейс на русском.

## Попробовать

Тестовый сайт: https://ai-coach-live-training.breezyolm11.chatgpt.site

Доступ к публикации — владельцу через аккаунт ChatGPT. Ссылка становится рабочей после успешного развёртывания; статус публикации сообщает агент.

1. Открой ссылку в Safari или Chrome на телефоне.
2. Выбери навык: чеканка, приседания или баланс.
3. Нажми «Начать тренировку» и разреши доступ к камере.
4. Установи телефон устойчиво, чтобы были видны плечи, колени и обе стопы.
5. По желанию включи голос; тренер комментирует наблюдаемые движения.
6. Заверши занятие: итог сохраняется на этом устройстве без видео.

«Сначала посмотреть демо» запускает явно обозначенную симуляцию без камеры и ключей. Демо не записывается в историю. «Открыть видео» позволяет анализировать локальный видеофайл, который не отправляется на сервер.

## Что реализовано

- Камера, смена камеры, пауза, продолжение и завершение.
- MediaPipe Pose Landmarker Lite: настоящий анализ позы в браузере.
- Скелет поверх видео, текстовые и голосовые подсказки.
- Завершённые подъёмы стопы для чеканки, циклы приседаний и подсказки для баланса.
- Итог занятия и локальная история последних восьми сессий.
- Адаптивный интерфейс с вертикальным live и комментариями по образцу референса.

## Ограничения

Это проверяемый MVP, а не профессиональная спортивная экспертиза. MediaPipe определяет позу; контекстные сообщения выбираются правилами по положениям суставов, видимости и фазам движения. Произвольный текст цели служит названием тренировки; тип анализа задаёт выбранный навык.

Мяч не отслеживается: счётчик показывает движения стопы, не касания мяча. Для качественного распознавания нужны свет и устойчиво установленная камера. После первого запуска модель загружается с CDN; для этого нужен интернет. Озвучивание зависит от голосов браузера/ОС.

Видеокадры не отправляются на сервер и не сохраняются приложением. В localStorage хранятся настройки и краткие итоги. MediaPipe/WASM загружаются с jsDelivr и Google Storage, шрифт — Google Fonts. Публичной трансляции другим зрителям нет: это приватный экран тренировки.

## Локальный запуск

Нужен Python 3 для раздачи файлов:

```sh
cd /Users/naranochirov/AI-Coach
python3 -m http.server 4173 --bind 127.0.0.1
```

Открой http://127.0.0.1:4173 на этом компьютере. Камера на телефоне требует HTTPS; для неё используй опубликованную ссылку, а не HTTP-адрес компьютера в локальной сети.

Node.js нужен только для тестов и сборки, npm-зависимостей нет:

```sh
node --test engine.test.mjs
node scripts/build.mjs
```

В текущем окружении переносимый Node находится в `/private/tmp/ai-coach-node/bin/node`; этот временный путь не требуется для опубликованного приложения.

## Файлы и команда

- `AGENTS.md` — правила работы и разделение задач.
- `index.html`, `styles.css` — интерфейс (frontend agent).
- `coach-engine.js`, `engine.test.mjs` — распознавание и тесты (vision agent).
- `app.js` — камера, сессия и интеграция (root).
- `docs/TEST_PLAN.md`, `docs/AI_STRATEGY.md` — приёмка и журнал (QA agent).
- `.openai/hosting.json` — идентификатор тестового сайта.

Официальная документация: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js).
