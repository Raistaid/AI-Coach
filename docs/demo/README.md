# Запасное видео для защиты

Сюда кладётся заранее записанное вертикальное видео чеканки (`keepie-uppie.mp4`, 9:16, 30–60 секунд, хороший свет, мяч контрастного цвета, всё тело в кадре).

Зачем: если на сцене не будет света, интернета или камера откажет, приложение анализирует этот файл по-настоящему через кнопку «Открыть видео». Это не запись экрана и не симуляция: поза и мяч распознаются на устройстве в момент показа.

Как снять:
1. Телефон на земле у стены, 2–3 метра до человека.
2. Последовательно: стойка 3 секунды → 6 подъёмов стопы без мяча → подброс и одно касание 3 раза → серии касаний.
3. Проверить файл заранее через «Открыть видео» на демо-телефоне и записать результат в docs/TEST_PLAN.md.

Видео не коммитить в репозиторий, если оно содержит узнаваемого человека без согласия. Файл хранится локально на демо-устройстве.
